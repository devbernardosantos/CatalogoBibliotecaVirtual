# CatalogoBibliotecaVirtual
Esse repositório é para uma atividade da faculdade. O propósito é a criação de uma landing page para um catálogo de biblioteca virtual.

1. Tecnologias Utilizadas
HTML5: Estruturação semântica utilizando tags como <header>, <nav>, <main>, <section> e <footer>.
CSS3: Layout responsivo construído com Flexbox (para o cabeçalho) e CSS Grid (para a grade de livros), além do uso de variáveis no :root e Media Queries para adaptação mobile.
JavaScript (Vanilla): Manipulação da DOM para interatividade sem dependências externas.

2. Funcionalidades Implementadas
Catálogo de Livros Responsivo: Exibição do acervo em formato de grade autoajustável.
Busca em Tempo Real: Filtro dinâmico que oculta os itens do catálogo que não correspondem ao texto digitado na pesquisa.
Validação de Formulário: Bloqueio do comportamento padrão de envio (preventDefault) e verificação customizada exigindo pelo menos 3 caracteres no campo de título da sugestão.

3. Como Executar o Projeto
Como se trata de um projeto front-end estático, basta adicionar as seguintes instruções básicas:
Faça o clone do repositório (git clone <url>).Abra o arquivo index.html diretamente em qualquer navegador web.
